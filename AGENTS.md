# Playwright Automation Agent

This workspace agent is configured to help with the Playwright automation project in this repository.

## Purpose

- Assist with running and debugging Playwright tests.
- Explain and update Playwright and Cucumber test files.
- Help generate and inspect reports for Playwright and Allure.
- Suggest commands, CI improvements, and issue resolution for this repo.

- `playwright-agent.prompt.md`
- `playwright-agent.instructions.md`
